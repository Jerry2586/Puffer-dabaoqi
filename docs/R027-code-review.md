# R027 代码审查与验证记录

日期：2026-10-28。范围：主题中心导出合同、打包器高级配置、完整 Android 客户端、运营配置读取及发行文件集合。本批修复先完成源码提交，后按用户明确指令进入正式发布：打包器 0.7.2、主题中心 0.4.3。发布仍需通过版本合同、测试、Windows 构建和附件校验；不部署生产。

## 修改前代码审查

发现旧原生宿主仅实现有限字段及页面，完整主题与短剧页面不能通过兼容检查。请求与运营同步共用串行执行路径，排队、服务目录恢复和读取缺少统一总时限；本地素材没有单范围读取；外链在实际启动 Activity 前报告成功。高级配置的存储、底包能力和真实 Manifest 也没有贯通。

## 修改后代码审查

主线程人工审查与自动测试分别执行。复核范围包括原生宿主、服务路由、请求调度、资源响应、运营合并与缓存、JavaScript 桥、共享 Vue 页面、主题能力合同、AXML 修改及发行清单。两次独立代理审查因服务 429 未完成，不能作为独立审查通过的证据；本报告不宣称全仓逐行审计。

已修复的具体问题：

- 完整 Vue 客户端以版本化源码快照构建进 Android 底包，包含短剧、会员等页面；主题只传数据与素材。新旧底包分别按实际能力校验，不删除兼容性门禁。
- Theme ZIP 由用户手动导出、上传。两中心无自动发现、心跳、主题下发或运行时源码依赖。
- Scheme/Host 在保存、底包能力、AXML 独立 VIEW 入口和客户端处理之间保持一致；渠道随原生请求发送。未接入统计 SDK 的配置不能虚假通过构建。
- 内容、认证、运营请求使用独立执行通道。统一总时限包含排队、服务目录恢复、重试和读取，完成回执至多一次；销毁后抑制迟到回调。POST 不自动重放。
- 复核时发现服务目录实际连接没有附加总时限，现已修复，并用真实停滞 TLS socket 验证超时后工作线程也能结束。
- 并发关闭时对 ConcurrentHashMap.values.toList 的竞争会触发异常，现直接遍历弱一致视图；socket 断开不阻塞定时器或 Activity 关闭。
- 本地素材支持单范围 206/416，防止路径穿越；只运行自带可信页面，不执行主题 HTML/JS。范围测试使用合成字节，不等同于真实影片解码播放验收。
- 外链以 UI 线程真实启动结果异步回执；Android 新版返回手势和旧版返回键都转给 WebView。
- 运营响应严格校验协议、设备和版本，缓存按服务、设备及主题隔离；合并业务内容时保留已打包主题外观。素材基于实际响应服务地址解析，过期认证响应不能清除新令牌。
- 发行清单补入 core/advanced-config.cjs。新增隔离暂存测试，验证已发行文件的本地依赖闭包，避免源码可运行而桌面成品缺文件。

最终定向审查没有发现阻止本批源码提交的未处理问题。生产业务和物理设备验收仍按以下边界单独进行。
